# Piezo VBR-Sen

ESP32 固件,用 IO32 的模拟输入(ADC1_CH4)读取一个压电振动传感器,标定出"空闲电平=0%、接近 0V=100%"的振幅曲线,通过串口实时输出采样事件,并用一颗 LED 同时兼顾"心跳"和"振动强弱指示"两种用途。

当前版本:见 [src/main.cpp](src/main.cpp) 顶部 `FW_VERSION` 宏(`?` 命令和上电横幅也会打印)。完整改动历史见 [CHANGELOG.md](CHANGELOG.md)。

> 本项目前身叫 esp32_DataCollection_AdcPiezo(还有一版基于 IO13 数字脉冲计数的 SQ-SEN-200 方案),数字通道已完全移除,现在只有 IO32 这一路模拟通道。

## 硬件接线

| 信号 | 引脚 | 说明 |
|---|---|---|
| 振动传感器模拟输出 | **IO32**(ADC1_CH4) | 满幅 0~3.3V,11dB 衰减,12 位分辨率(0~4095) |
| 传感器插头的 GND 邻脚 | **IO33** | 与 IO32 共用同一个插头,现场接到 GND;固件把它设为纯输入(不驱动、不加内部上拉),避免和外部地线对冲 |
| 状态 LED | **IO23** | 心跳(每 1s 翻转)+ 振动强弱指示(见下文),共用一颗灯 |

IO13 上的旧数字脉冲方案(配合 SQ-SEN-200)已经完全删除,不需要再接线。

## 编译 / 烧录

PlatformIO 项目,`espressif32` + `arduino` 框架,见 [platformio.ini](platformio.ini)。

```bash
pio run                              # 编译
pio run -t upload --upload-port COMx # 烧录(默认 upload_speed 921600)
```

串口调试波特率固定 **115200**(`Serial.begin(115200)`,`platformio.ini` 里 `monitor_speed` 也是这个值,两边要对得上)。

## 基本流程

1. 上电后串口打印版本号和 `ready, send 's' to start ('?' for help)`,此时**不会**自动做任何标定。
2. 用 `T YYYYMMDD HHMMSS` 设置墙上时间(或者调试时直接发一个空格走快捷方式,见下文)。
3. 发 `s` 开始采集:先做 10 秒钟的"空闲电平"标定,标定期间会持续打印时间戳 + 原始值 + 电压;标定结束后打印一份摘要和 1~10 挡"0% 基线"菜单,发数字选一档,正式进入采集状态(RUNNING),开始按事件输出。
4. 发 `p` 随时停止;发 `r` 只清计数器和缓冲,不动时钟和标定结果。

## 串口命令一览

| 命令 | 作用 |
|---|---|
| `s` / `S` | 开始采集(必须先设好时钟)。会先做 10s 标定,期间打印 `时间 raw=... v=...V`,标定完打印 1~10 挡菜单等你选 |
| `1` ~ `10` | 标定结束后选一档"0% 基线"偏移(见下文"标定与 0% 基线"),选完才真正开始输出振幅事件 |
| `p` / `P` | 停止采集(缓冲里还没发完的数据会继续发完);同时退出 `cal`/`adccnt` 调试模式 |
| `r` / `R` | 只清空事件计数(`ccc` 归 1)和发送缓冲,不动时钟、不重新标定,并回显当前时间 |
| `T YYYYMMDD HHMMSS` | 设置墙上时间,例如 `T 20260827 140000`。刷新之后每整分会打一行 `time:` 基准 |
| `<space>`(单独一行空格) | 双重含义快捷键:平时是"快速设时间"(设成 2026-09-09 09:00:00,纯为了调试方便);如果 `adccnt` 连续输出模式正开着,则改为退出该模式,不动时钟 |
| `cal` | 独立的标定调试命令,不需要先设时钟:单做一次 10s 标定 + 打印 raw/电压,标定一结束就自动停止打印(不会像 `s` 那样继续进入正式采集) |
| `adccnt` | 采集运行中(RUNNING)把 >1% 的输出门槛临时关掉,让每次采样都输出一行(方便连续观察读数)。串口带宽在 2.5kHz 采样率下跟不上,会大量丢包发不出去,这是预期现象。发空格退出,恢复只在 >1% 时输出。这个开关只影响是否发送,**不影响振动指示灯**(LED 依然只认真正 >1% 的样本) |
| `ledoff` / `ledon` | 关闭 / 重新打开心跳 LED 的翻转;振动指示灯的强制点亮逻辑完全不受影响,该亮还是会亮 |
| `time` | 打印当前墙上时间(或提示未设置) |
| `ping` | 回 `pong`,纯连通性测试 |
| `?` | 打印上面这份帮助 + 当前状态(采集状态 / 时钟 / ADC 阶段 / 心跳开关) |

命令大小写:`s`/`p`/`r` 支持大写(`S`/`P`/`R`);其余命令区分大小写、按上表原样输入。所有命令都是"一行一条",以回车结束。

## 标定与 0% 基线

- 空闲(无振动)对应传感器**高电平**,定义为 **0%**;持续大振动、电压接近 0V,定义为 **100%**。
- 标定(`s` 或 `cal` 触发)持续 10 秒,统计这段时间里电压的均值 `mean` 和峰峰噪声半幅 `noise`,标定完打印:

  ```
  ADC calibrated: idle=3.129V noise=+-0.000V (n=25000)
  1) -0.010V set to zero(0%)
  2) -0.020V set to zero(0%)
  ...
  10) -0.100V set to zero(0%)
  send 1~10 + enter to select
  ```

- 发 `1`~`10` 选一档,`zero(0%) = mean - N × 10mV`(范围 -10mV ~ -100mV,10 档、每档 10mV)。电压高于这个 `zero(0%)` 都算 0%。
- 100% 端点是固定的:电压低于 100mV 就算 100%,`zero(0%)` 和 100mV 之间做线性映射得到 0~100% 的幅度。
- 如果标定出来的 `mean` 偏离期望的空闲电压(`ADC_NOMINAL_IDLE_V`,当前设成 3.130V)超过 0.05V,标定摘要后面会多打两行英文提示:

  ```
  WARNING: ADC idle level drifted to 3.070V (nominal 3.130V, delta -0.060V)
  - still usable but check sensor/wiring
  ```

  这只是提醒,不会阻止你继续选档、继续采集。

标定期间(不管是 `s` 还是 `cal` 触发的)都会每 200ms 打印一行 `时间  raw=xxxx v=x.xxxV`,方便肉眼确认标定过程中传感器读数是不是真的静止;标定一结束这行就自动停。

## 输出格式

**振幅事件行**(RUNNING 状态下,幅度 >1% 才会输出,除非开了 `adccnt`):

```
ccc tt.ttttS a.aaV vvvv xx%
例:04 23.2311S 2.21V 4012 23%
```

- `ccc`:事件计数器,2 位起,从 1 开始,`s`/`r` 时归零
- `tt.ttttS`:距最近一条 `time:` 整分基准的秒偏移,4 位小数(0.1ms 分辨率),末尾跟一个字母 `S`
- `a.aaV`:校准后的电压(2 位小数),背景参考值
- `vvvv`:该次 ADC 原始采样值(0~4095),背景参考值
- `xx%`:幅度百分比(0~100,四舍五入),由电压换算而来,这才是主要数据

**整分时间基准行**(设了时钟就会打,不管在不在采集):

```
time: YYYY-MM-DD HH:MM:00 a.aaV vvvv xx%
```

末尾附带打印这一刻的电压/原始值/幅度。后续事件行的 `tt.ttttS` 就是相对这一行的秒偏移。

**标定期间的调试行**:

```
YYYY-MM-DD HH:MM:SS  raw=vvvv v=x.xxxV
```

## LED 行为

一颗 LED(IO23)身兼两职:

1. **心跳**:每 1 秒翻转一次,证明主循环没卡死。`ledoff`/`ledon` 可以关闭/恢复。
2. **振动强弱指示**:检测到 >1% 的样本,LED 会被强制点亮,盖过心跳的输出;点亮时长正比于幅度(`pct × 10µs`,100% 对应 1ms)。这部分是硬件定时器驱动、不经过主循环轮询,尽量做到实时——ADC 定时器回调检测到事件直接拉高引脚,另一个独立的一次性定时器精确计时到点后再交还给心跳。振动持续时,新样本会不断给这个"关灯倒计时"续命,所以持续振动时灯会一直亮,松手后再多亮一小段(对应最后一次达标采样的幅度)才熄灭。

因为最长才 1ms,这个指示灯的点亮基本已经短到肉眼看不出明暗变化,更适合用示波器/逻辑分析仪去量,如果需要肉眼可见的效果,需要调大 `LED_EVENT_US_PER_PCT`。

## 已知的硬件限制(务必留意)

- **`ADC_SAMPLE_US`(采样周期)不能随便调小**。ADC 定时器回调每次要读 2 次 ADC(一次原始值、一次校准电压),实机二分法测出的硬上限在 220~250µs 之间——超过这条线,`esp_timer` 所在的核心会被沾满,喂不上任务看门狗,10 秒内必定 `task_wdt` 重启。当前默认 400µs(2.5kHz),留了约 1.6 倍安全余量。以后如果往这个回调里加东西(哪怕看起来很轻),**必须重新做二分法压测**,不能凭感觉判断够不够快——这个坑已经踩过不止一次。
- **串口带宽跟不上 2.5kHz 全量输出**。正常情况下只有 >1% 的样本才发送,足够;但 `adccnt` 连续模式会让每个样本都排队发送,115200 波特率下大部分会被丢弃(`adcDropped` 计数),这是预期现象,不是 bug。
- ADC 读数即使传感器完全静止也不是绝对恒定的——现场噪声、供电波动都会体现在标定出的 `noise` 里,标定这 10 秒务必保持传感器不受干扰。
